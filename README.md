# Linia App

**One Card, Multiple Wallets.**

Linia is a smart budgeting and wallet management app that helps you organize your money across multiple wallets from a single card.

## Download

Get the latest version here:

[Download Linia App](https://github.com/VictorAsiya/Linia-app/releases/latest/download/YourFileName.apk)

Or browse all versions on the [Releases page](https://github.com/VictorAsiya/Linia-app/releases).

## Installation (Android)

1. Download the APK file using the link above.
2. Open the downloaded file.
3. If prompted, allow **Install unknown apps** for your browser or file manager.
4. Tap **Install** and open the app.
